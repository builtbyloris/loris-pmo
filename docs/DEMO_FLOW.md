# Loris PMO V1 Portfolio Demo

Target duration: 7–9 minutes. Use the isolated project from `DEMO_DATA_GUIDE.md`. Keep the narrative focused on connected project intelligence rather than opening every form.

| Time | Action | Explain | Value demonstrated |
|---:|---|---|---|
| 0:00 | Log in and open **Portfolio** | Accounts are operator-created; there are no default credentials or startup fixtures. | Secure, empty-by-default product foundation |
| 0:30 | Open the demo project | Point out health, KPIs, budget, overdue work, risks, and attention signals. | One factual project control center |
| 1:15 | Open **Work Planning**, then Kanban and Timeline | Move between views without duplicating records; show a dependency and milestone. | Shared task model and deterministic schedule state |
| 2:00 | Open **People & workload** | Show assignments, availability, and explicit heuristic warnings. | Connected resources without invented capacity hours |
| 2:35 | Open **Finance** | Explain paid = actual, pending = committed, planned = forecast-only. | Backend-owned financial calculations |
| 3:15 | Open **Control** | Show the 5×5 risk matrix, an issue, and a governed change decision. | Deterministic risk scoring and human governance |
| 3:55 | Open **Project Memory** | Show a meeting, action item, decision, Project Log, and Activity. | Durable context separated from technical audit history |
| 4:35 | Open **AI Copilot** | Ask a narrow project question and point to resolved evidence. | AI as an evidence-grounded, read-only copilot |
| 5:20 | Show **Insights/Recommendations** and **Daily Briefing** | Explain explicit generation, freshness, and that acceptance records agreement only. | Bounded proactive intelligence with human review |
| 6:05 | Run an existing **Scenario Analysis** | Emphasize that simulation never changes real dates, assignments, or budgets. | Deterministic what-if analysis plus interpretation |
| 6:40 | Show a completed meeting’s assistant proposals | Explain proposal-by-proposal confirmation and backend validation. | The only operational AI path remains human-confirmed |
| 7:15 | Open **Documents**, upload a small text/PDF file, then search it | Show bounded extraction and project-scoped evidence. | Private project knowledge without sending whole files blindly |
| 8:00 | Open **Reports & data** | Generate a report, download PDF/XLSX, and show import preview without confirming. | Deterministic reporting and controlled portability |

## Closing message

Loris PMO is a connected PM intelligence application: PostgreSQL holds operational truth, deterministic services calculate facts, Gemini interprets bounded evidence, and users retain control over every operational change.
