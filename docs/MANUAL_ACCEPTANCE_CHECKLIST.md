# V1 Manual Acceptance Checklist

Expected time: 10–15 minutes. Use non-sensitive local or isolated demo data. Record any real blocker before approving the `v1.0.0` tag.

- [ ] Log in, log out, and log in again; confirm no default account exists.
- [ ] Review Portfolio totals, filters, project cards, and one project opening.
- [ ] Review Project Overview health, KPIs, alerts, budget, control, and recent activity.
- [ ] Review Tasks in List and Kanban; verify the same task/status appears consistently.
- [ ] Review Timeline and Milestones at desktop and mobile width.
- [ ] Review People, Stakeholders, assignments, and Workload warnings.
- [ ] Review Finance totals, expense status handling, and category breakdown.
- [ ] Review the risk matrix, linked issue, and change-request decision history.
- [ ] Review Project Log, Meetings/actions, Decisions, and read-only Activity.
- [ ] Recalculate Intelligence; verify health/alerts are factual and explainable.
- [ ] Ask one narrow Assistant question only if Gemini is configured; inspect evidence.
- [ ] Review Insights, Recommendations, Briefing, Weekly Review, and Scenario boundaries.
- [ ] Upload/download/delete a small non-sensitive document; test knowledge search.
- [ ] Generate a report; open PDF/XLSX/CSV; preview an invalid import without confirming.
- [ ] Switch English/Italian and light/dark modes; check labels, contrast, and layout.
- [ ] Confirm key navigation and basic responsive behavior at approximately 390 px width.
- [ ] Verify no secret, personal identifier, or local path appears in screenshots or UI errors.
